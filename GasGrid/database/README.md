# Database scripts

Run the numbered Oracle SQL scripts in order in a dedicated practice schema using Oracle SQL Developer or SQL*Plus. `01_create_tables.sql` creates the tables; `02_constraints.sql` adds constraints; `07_sequences.sql` creates sequences used by later examples; `03_insert_sample_data.sql` inserts sample rows. For a clean run, use this practical order: 01, 02, 07, 03, then 04-10. Some scripts demonstrate COMMIT/ROLLBACK and are intended for a test schema.

These are Oracle SQL/PLSQL learning scripts. The uploaded Flask application itself currently uses SQLite; the scripts are not connected to its runtime database.
