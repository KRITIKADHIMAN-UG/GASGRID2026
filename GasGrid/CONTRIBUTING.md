# Contributing to GasGrid

1. Create a branch for your change.
2. Keep Python, HTML, CSS, and JavaScript readable and add comments where logic is not obvious.
3. Do not commit `gasgrid.db`, passwords, API keys, or `.env` files.
4. Install requirements with `python -m pip install -r requirements.txt`.
5. Run tests with `python -m unittest discover -s tests -v`.
6. Test the website locally before opening a pull request.
